# Pirate Wallet Android SDK

This directory contains the Android wrapper and packaging inputs.

Canonical docs:

- [Android SDK overview](../../docs/native-sdk-android.md)
- [Android SDK API reference](../../docs/native-sdk-android-api.md)

The default SDK embeds Sapling proving parameters. The optional
`pirate-android-sdk-external-release.aar` uses host-provided files to reduce
APK size; see the overview for initialization and download requirements.
